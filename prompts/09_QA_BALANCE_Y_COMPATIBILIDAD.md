# PROMPT 09 — QA y balance

Actúa como QA independiente. Prueba cliente, servidor dedicado, dos clientes, compras y recompensas simultáneas, desconexiones, reinicios, migraciones, permisos, duplicación, apps bloqueadas, ausencia Cobblemon y versión exacta Cobbleverse.

Balancea tiempo para desbloquear apps y evita grind, inflación y exploits. Entrega QA_REPORT, BALANCE_REPORT, bugs priorizados y matriz de compatibilidad. No declares compatible algo no probado. Corrige solo tareas aprobadas y en ramas separadas.
