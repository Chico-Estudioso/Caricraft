# PROMPT 03 — Teléfono e interfaz

Implementa CariPhone con pantalla de inicio, iconos, saldo, notificaciones, navegación, catálogo, tienda, cartera, misiones, dúo y crónicas placeholder.

Diseño colorido, divertido, legible, adaptable a GUI scale, traducible. Estados bloqueado/disponible/cargando/error/sin datos. No usar assets de Cobbleverse ni marcas no autorizadas.

La UI no decide precios ni desbloqueos. Solicita snapshots y envía acciones tipadas al servidor. Prueba abrir/cerrar, navegación, desconexión y rechazo de acciones no autorizadas.
