# Contribuir

1. Lee `CLAUDE.md`, `AGENTS.md` y `docs/`.
2. Crea una rama desde `main` (`feat/...`, `fix/...`, `docs/...`, `test/...`).
3. Haz cambios acotados y añade tests.
4. Ejecuta `./gradlew build` (incluye los tests).
5. Actualiza documentación y `CHANGELOG.md`.
6. Abre un PR siguiendo la plantilla.

No añadas dependencias no verificadas ni assets/código sin licencia compatible.
