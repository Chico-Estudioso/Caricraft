# Project Charter

Visión: convertir el servidor compartido en una aventura cooperativa persistente, accesible desde un teléfono dentro del juego.

Pilares: cooperación; teléfono divertido; apps desbloqueables con Carins; misiones; crónicas; integración Cobblemon opcional; ampliabilidad.

Usuarios iniciales: dos jugadores. Diseñar datos para poder ampliar a grupos más adelante, sin implementar grupos en MVP.

No objetivos MVP: dinero real, cuentas externas, IA generativa, servicios cloud, NeoForge, reimplementar Pokédex/PC/radar/mapa/economía ya presentes.

Decisiones: un mod Fabric 1.21.1; compras de apps principales compartidas por el dúo; cosméticos potencialmente individuales; precios/recompensas configurables.
