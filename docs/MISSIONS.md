# Misiones

Tipos: individual, cooperativa, hitos, diaria/semanal opcional y expedición temporal.

Ciclo: disponible → aceptada → progreso → completada → reclamada. También bloqueada, abandonada y caducada.

Objetivos base: explorar bioma, visitar lugar, recorrer distancia, craftear/entregar ítem, descubrir estructura si hay evento fiable. Objetivos Cobblemon solo con API exacta validada.

Progreso derivado de eventos confiables del servidor. Reclamación idempotente; recompensa validada y emitida por servicio económico.
